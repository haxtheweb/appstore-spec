appstore-spec is one of several schema specifications in the HAX ecosystem. Explore the others:

*   [JSON Outline Schema](https://haxtheweb.github.io/json-outline-schema/) — the content structure, site navigation, and metadata schema used by HAXcms.
*   [HAX Schema](https://haxtheweb.github.io/hax-schema/) — the full haxProperties contract for element authoring.
*   [HAX Element Schema](https://haxtheweb.github.io/hax-element-schema/) — the lightweight virtual DOM object format used for demoSchema, insertion, and conversion workflows.
*   [Merlin Schema](https://haxtheweb.github.io/merlin-schema/) — the schema for Merlin's conversational options, programs, and voice/shortcut metadata.
